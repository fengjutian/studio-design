# 时间线与成片导出

## 当前能力

- 时间线顺序独立于 Scene / Shot 的叙事结构。
- 选中镜头可以向前或向后移动。
- 项目保存后保留 `timelineOrder`。
- 导出前检查项目位置以及每个镜头的本地 MP4。
- FFmpeg 将素材统一到 1920×1080、30fps、H.264、YUV420P。
- 输出文件自动保存到项目的 `exports/`，不会覆盖已有成片。
- 支持逐镜头入点、出点裁剪。
- 支持导入一条主配乐、调整音量并导出为 AAC。
- 工作台可以按照时间线连续播放镜头并同步预听配乐。

## 安全边界

Rust 导出命令会规范化所有路径，并确认每个输入都是当前项目 `generations/` 目录下的 MP4。前端不能通过该命令读取或拼接项目目录之外的文件。

## 当前限制

- 暂不支持镜头原声、对白与多条音轨混音。
- 暂不支持转场与字幕。
- 导出进度目前是阶段状态，不是精确百分比。
- 开发版本调用系统 `ffmpeg`；发布安装包需配置可信 sidecar。

这些限制确保首个粗剪导出链路足够稳定。下一阶段可以基于统一后的时间基准加入镜头原声、淡入淡出与精确进度事件。
